# Task Tracker - Frontend

Vue 3 SPA-приложение для управления задачами.

## Технологии

- **Vue 3** - Composition API, `<script setup>`
- **Vite** - сборка и разработка
- **Pinia** - управление состоянием
- **Vue Router** - навигация
- **Axios** - HTTP запросы
- **Tailwind CSS** - стилизация
- **TypeScript** - типизация

## Установка

```bash
npm install
```

## Переменные окружения

Скопируйте `.env.example` в `.env` и настройте:

```env
VITE_API_URL=http://localhost:3001
```

## Основные функции

### Авторизация

- ✅ Вход по email и паролю
- ✅ JWT токен сохраняется в localStorage
- ✅ Защищённые роуты (`/tasks`)
- ✅ Гостевые роуты (`/login`)
- ✅ Обработка истечения токена (401)

### Список задач

- ✅ Загрузка с сервера
- ✅ Пагинация
- ✅ Фильтрация по статусу
- ✅ Поиск по названию (с debounce 400ms)
- ✅ Состояния: загрузка, ошибка, пустой список

### CRUD операции

- ✅ Создание (модальное окно)
- ✅ Редактирование (модальное окно)
- ✅ Удаление с подтверждением
- ✅ Быстрое изменение статуса (select)

### UI/UX

- ✅ Адаптивный дизайн
- ✅ Уведомления об успехе/ошибке
- ✅ Лоадеры для всех операций
- ✅ Скелетоны при загрузке
- ✅ Семантическая вёрстка

## Архитектурные решения

### Хранение токена

- Токен хранится в `localStorage` и Pinia store
- При инициализации приложения токен восстанавливается из `localStorage`

### Обработка ошибок

- `401` → автоматический логаут с уведомлением
- Сетевые ошибки → уведомление пользователя
- Ошибки валидации → показ в форме
- Ошибки сервера → уведомление
